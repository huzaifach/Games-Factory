# TRUCK ART RALLY — Slice Scope (M1 Vertical Slice)

**What this is:** the first playable vertical slice of Truck Art Rally — a desi-cultural arcade racer + generative truck-art decorator. Landscape, mobile-first, touch + desktop. All in-game UI in English, globally themed (truck-art visual identity kept as the globally fascinating art style; all text universally understandable).

**This slice = ~55% of the full vision** (see BUILD-LEDGER.md for the full roadmap).

## In this slice (playable now)
- **Generative Truck-Art Studio** — procedural motifs (floral medallions, peacock panels, roses, poetry banners, chrome finishes, tassels, mudflaps) composited live on the truck as one canvas texture. Paint/pattern/color pickers, randomize, 3 save slots (localStorage), paint-budget shop (earn coins by racing).
- **Grand Trunk Road Tour** — 3 legs, ~90s each: LAHORE HIGHWAY (day, dense traffic), SALT RANGE (dusk, winding mountain road), KARACHI COASTAL (night rain, neon reflections). Each leg has a one-line plain-English explanation.
- **Style-point racing** — near-misses (slow-mo + zoom punch), drifts (smoke), airtime feed a Style meter; high style = more speed + more coins; police chase at max style (dodge to bank a bonus, ram = busted).
- **Traffic AI** — rickshaws, buses, bikes, donkey carts with distinct behavior.
- **Medals & records** — bronze/silver/gold per leg, best records saved.
- **Full synthesized WebAudio** — engine, horn, dhol stingers, siren, rain, skid, crash, fanfare.
- **Game feel** — eased steering, screen shake, squash-and-stretch, dhaba signs/birds/dust ambient life.
- **How-to-Play panel** on the menu (plain global English).
- **Controls** — touch drag steering + DRIFT/HORN buttons; desktop arrows + Space + H. Full-screen responsive, loading screen with live progress + honest retry.
